## Hypothesis and novelty

F2 learns a common linear/quadratic return mapping by pooled EW ridge, treating correlated/noisy daily cross sections equally apart from age. A feasible GLS learner may estimate these premia more efficiently using the covariance forecast available BEFORE each training outcome. This is different from the earlier ceiling_estimators.py WLS diagnostic: that estimated each day's cross-sectional factor returns with diagonal stock weights, then evaluated a factor ceiling/timer. Here the full lagged factor-plus-specific covariance changes temporal information weighting in the actual pooled learner and the original net portfolio scorer is the endpoint. It is also different from Wave5 P, which changed the conditional mean specification by scaling design columns.

This is a hypothesis, not a claim that estimated GLS must improve. Wrong covariance, drifting premia, low-volatility sample selection, noisy beta and changed ridge geometry can all make it worse. Beck/De Nard/Wolf, Improved Inference in Financial Factor Models (2023), motivates heteroskedastic efficiency only; no published gain is assumed here. Source: https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4107472 .

## Frozen algorithm — one primary configuration

Keep F's complete risk, execution, sizing, sleeve 0.05, limits and Gamma variance model unchanged. Produce the baseline F forecast first. For matured label day u>=64, use design D from characteristics[u-1], standardized trailing beta estimated before u, and y=R[u]-beta[u]*market[u]. Construct Omega_u from V3's specific variance and unscaled characteristic-factor covariance estimated through u-1, congruence-rescaled by F's causal variance multiplier for target u. Undo the allocator's 0.3 risk discount when using this as a statistical observation-noise model. Nothing used to construct Omega_u may depend on R[u].

Apply Omega_u^{-1} with Woodbury. Profile out an unpenalized cross-sectional intercept in the precision inner product. Update 27x27 Gram and 27-vector moments using the same EW1008/EW252 decays as F2. At solution time add ridge 0.1 times the diagonal of each average weighted Gram, floored at 1e-12 times max(mean diagonal,1e-12), rather than an arbitrary absolute precision-unit penalty. Use slow/fast 50/50 coefficients for the first 13 columns, slow coefficients for squares and beta. Require 126 matured GLS labels. Before target 253 retain baseline forecasts; afterwards blend 50% F2 and 50% GLS, with no sign/feature selection or hyperparameter changes. Labels stop at t-1 for forecast row t; today's design uses X[t-1]. All intermediate state is session-owned and reset.

One control is permitted only as attribution if this candidate passes the development shortlist: replay the SAME candidate and baseline F without their explicit market sleeve. No other learning variant, seed search, blend search or combination with the correlation candidate in this batch.
