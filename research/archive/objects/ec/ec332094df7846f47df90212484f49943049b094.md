# GLS attribution review — covariance weighting and shrinkage work jointly

29 October 2026. Branch: research-gls-attribution-review-20261029. Frozen main: ebf1ff1636e263d5fa98ce724cf65dc912d3d0c3. Original GLS parent:94f27f8e50216f4cf4daaf285f583b066ddcf4cc.

## Executive summary

The original GLS specification reproduces **1.533215561** net Sharpe versus **1.493439948** for F. The matched unweighted control, with the same coefficient-wise ridge, intercept treatment, startup and blend, scores **1.495931191**. Its difference from GLS is **+0.037284369**, positive in all three chronological stages and both halves. Thus the historical gain is not explained by changing ridge alone or the training startup.

However, weighting and regularization interact strongly. With trace-matched isotropic ridge, the weighting contrast shrinks to **+0.006654173**; without the explicit market sleeve it reverses to **-0.010975068**. Under the original coefficient-wise penalty, the no-sleeve contrast remains **+0.025782996**. The supported mechanism is covariance-aware regularized estimation, not a penalty-independent GLS advantage.

The source review and separately implemented dense reference found no lookahead or regression-algebra defect within the tested scope. This is not an independent-person/subagent review. Two strict default-solver oracle comparisons failed at a few1e-10; verification-only numerical refinement resolves them without changing any production code or test tolerance. The failed receipts remain failed. All scored runs use the original solver.

**Decision:** retain unchanged GLS as the leading research candidate. Main remains the submission-ready F. No variant was promoted or combined, and nothing was submitted externally.

## Attribution: not covariance alone, not regularization alone

Let g be the EW-normalized training Gram matrix. The coefficient-wise penalty is0.1*diag(diag(g)); the isotropic control is0.1*mean(diag(g))*I. They have the same total trace for a fixed g but distribute shrinkage differently across coefficients. Both scale with the weighted loss. An algebra check multiplies precision by7 and preserves predictions. We deliberately avoid confounding covariance units with an unscaled absolute ridge penalty.

G_D minus O_D is+0.037284369, while G_S minus O_S is+0.006654173. The difference-of-differences is+0.030630197. Its95% interval still includes zero. These controlled historical comparisons are not a unique additive causal decomposition of profit because allocation, sizing and Sharpe are nonlinear.

The unweighted penalty change O_D minus O_A is only-0.000030436. The startup/blend bridge O_A minus F is+0.002521680. The full-start algebra identity control O_A0 reproduces F2. Removing the daily nuisance-intercept treatment changes GLS by only-0.000022812. Intercept handling and startup do not explain the main observed gain.

Full factor covariance adds0.009868643 over specific-only weighting D_D, concentrated in the third period. This is NOT a pure correlation ablation: D_D removes both diagonal and off-diagonal factor-risk contributions. A matched-total-diagonal variant was not registered or added after seeing results.

## Causal and independent-algebra checks

For target t, newest label u=t-1 uses design X[u-1], beta[u] estimated before u, and covariance through u-1. The F multiplier baseline[u] also uses only information before u. Prediction uses X[t-1], beta[t]. The intercept is a separate nuisance intercept for each training cross-section, not a pooled intercept or an alpha added at prediction.

A separate dense implementation rebuilds lagged betas, bases and covariance moments, then solves the full covariance system rather than using Woodbury. Raw forecast error versus GLS is7.86e-19. It shares the already audited F multiplier payload, not the GLS sufficient-statistics routine.

**Numerical exception:** two default-solver1e-10 cross-implementation checks fail: weights3.12e-10, economic-column maximum4.18e-10. Tighter Newton stopping alone still fails. A verification-only dense primal KKT refinement on the original active set reduces differences to5.69e-16 for weights and2.89e-15 for economics. Neither test tolerances nor the mathematical objective changed. The default and tightened-only failures remain recorded; no refined solver was used for any reported market score.

252 constructed-data assertions pass for the six controls;48 actual-data assertions pass for G_D/O_D;17 refined dense-oracle/algebra assertions pass. These are workflow checks, not independent market experiments. All causal/prefix/reset/layout comparisons have zero error. The pre-existing stock-permutation weight tolerance1e-8 is unchanged. Input/scorer/source hashes match prior evidence. Separately recomputed Sharpe and beta match the reported values.

No actual-century GLS test, standalone GLS release-package audit or independent-person review was performed. Those remain separate release work. The result is a better-supported mechanism and code implementation, not proof of superior future Sharpe.
