# ML incremental-signal test — pre-registered, written before running

29 October 2026, 13:50 Europe/Paris. Question: does a causal nonlinear ML model predict next-day
market-residual returns beyond the current F2 forecast? This is a diagnostic gate. It changes no
production file.

## Data, features, target (all causal; zero-based day index t)

- **Features at decision t** (17 columns):
  - the 13 characteristics of X[t−1], cross-sectionally z-scored and clipped at ±4;
  - z(raw trailing beta[t]), using rows < t;
  - z-scored sums of market-residual return over [t−5, t−1], [t−21, t−1] and [t−252, t−22].
- **Target.** Market-residual return of day t, residual[t] = R[t] − beta[t]·m[t], demeaned and
  divided by its cross-sectional standard deviation on day t.
- **Training.** Refit every 252 days, starting at t0 = 1008. Each fit uses only pairs whose
  target day is < t0 + 252·j: all days 253 .. (refit day − 1), every 3rd day, all stocks.
  Predictions for the 252 days after each refit come from that fit.
- **Models,** fixed settings with no tuning and no early stopping:
  - GB: `HistGradientBoostingRegressor(max_iter=300, learning_rate=0.05, max_leaf_nodes=31,
    min_samples_leaf=2000, l2_regularization=1.0, early_stopping=False, random_state=0)`;
  - NN: `MLPRegressor(hidden_layer_sizes=(64, 32), alpha=1e-3, learning_rate_init=1e-3,
    batch_size=4096, max_iter=20, early_stopping=False, random_state=0)`, trained on every
    6th day.
- **Reference.** The F2 forecast (`handoff_v3` `f2_forecast`) for the same days.

## Metrics (out-of-sample days 1008..3778)

- Daily Pearson IC with the target. IC Sharpe = √252 · mean(IC) / std(IC), for each model and
  for F2.
- **Incremental signal.** Each day, residualize the ML prediction cross-sectionally on F2's
  prediction, then take its IC with the target. Report the incremental IC Sharpe, overall and
  by OOS half.
- Daily correlation between the ML and F2 predictions.

## Gate

A model goes on to a full-scorer test only if its **incremental IC Sharpe is ≥ 1.0 overall and
positive in both OOS halves**. The full-scorer test would add it as one forecast column in F2,
under a new plan. Otherwise ML on these features is closed for this project.
