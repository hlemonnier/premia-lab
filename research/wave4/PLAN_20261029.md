## Evidence and questions

Read WAVE3_RESULTS_20261029.md, ML_RESULTS_20261029.md, and the V3 production code. Boosting and a 64-32 neural network were already rejected on incremental forecast IC. Do not repeat those models on the same target. A constant-premium ceiling for 27 directions is not an upper bound on every conditional policy. High characteristic persistence does not test whether characteristic innovations contain information. Predictive IC is not the same objective as net portfolio Sharpe. Cost reduction is bounded by the fixed-path gross/net gap only if positions are fixed.

## Frozen experiments (no hyperparameter search)

B0: reproduce V3 under the supplied scorer; require absolute Sharpe difference <1e-9 before comparison. The local connector may require executable source transcription; record provenance and do not claim byte identity for transcriptions.

I1: incremental characteristic dynamics. Features: cross-sectional standardized changes over 1 and 21 days, projected off the current V3 27-column design using no outcomes. Fit residual returns minus the strictly causal F2 forecast with pooled EW ridge, half-life 1008, ridge 1, minimum 252 matured pairs. Prediction uses data before the target row. Add to F2; bound incremental cross-sectional RMS to 25% of F2 RMS. No sign flipping or feature selection after results.

R1: ML for specific risk, not another alpha model. Learn next-day squared characteristic-residual returns relative to the historical specific-variance forecast using HistGradientBoostingRegressor, Poisson loss, learning rate 0.05, max_iter 80, max_leaf_nodes 15, min_samples_leaf 200, l2_regularization 10, random_state 20261029. Features: 13 published standardized characteristics, standardized beta and log historical specific variance. Train on every fifth available day in the preceding 504 days, minimum 252 days, refit every 126 days. Labels are winsorized squared residual / lagged specific variance, capped at 25. Clip predicted ratios to [0.5,2], blend 50/50 with the EW variance: d_new=d_old*(0.5+0.5*ratio). Keep factor risk, alpha and market sleeve fixed. Fit and inference must be causal. No tuning if this fails.

C5/C80: same V3 with cost_horizon 5 or 80 instead of 20; control experiments for execution only. The actions are finite and registered, not a rolling parameter grid.

Cmix: causal full-information expert controller over C5, B0, C80. Shadow books are replayed independently with their own drift and costs. After at least 252 completed scored days, use EW252 mean and variance of each expert's net return to form shrunk weights: 50% fixed B0 plus 50% softmax of clipped annualized expert Sharpe in [-3,3]. Before 252 completed days use B0. Reweight weekly (21 trading days is also permitted only if declared before running; default five). Recompute actual traded-book drift and costs using the original scorer; do not average experts' already-net returns. No claims that this full-information online learner is deep RL.

Only if I1 or R1 passes may one I1+R1 combination be run, and only if both pass. Do not add a larger market sleeve. No PPO/SAC implementation in this wave: high-dimensional RL is not justified until information and low-dimensional control baselines are measured; installed submission dependencies exclude deep-learning frameworks.

## E2E failures and expected outcomes — before implementation

1. Misaligned feature/label or variance labels can leak one day: latest label at forecast row t is t-1; all feature rows <=t-1. Mutate returns and characteristics from a boundary; earlier forecasts and executed positions must remain unchanged (float tolerance 1e-10).
2. Prefix-dependent standardization/refits can leak future shape: compare full and prefix runs; same prefix inputs give same outputs.
3. Regime controls can use today's not-yet-earned expert reward: update only with returns published before the action, preserve scorer fee timing, and compare actual book cashflows, not proxy expert averages.
4. An approximate replay can create a fake improvement: B0 must reproduce first, use the original scorer without edits; store rows and source/data hashes.
5. ML risk can underestimate variance and inflate beta: positivity bounds, baseline fallback before maturity, actual beta/exposure checks and timing.
6. Stateful policy reuse can contaminate experiments: reset every book/model per replay; deterministic repeated/prefix run.

Only E2E tests are to be added; no post-implementation unit tests. Record exact commands, versions, identities, logs, outcomes, unrun checks and artifacts. Keep production untouched unless a candidate is fully checked. No submission or outgoing email is authorized by this plan.
