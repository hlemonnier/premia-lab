# Reproduce the frozen N0 review

Use branch `research-n0-frozen-review-20261030`, or the `code/` folder of the evidence archive. The original N0 implementation and all runtime files are inherited unchanged from the verified ten-job batch at `4d4561b`. No input CSVs are distributed.

## Required inputs

Restore the original `Quant Research Take-Home` folder, including its unchanged scorer and CSVs. The expected source SHA-256 hashes are included in `reference/evidence/inputs/source_identity.json` in this archive and in the prior evidence. `PRIOR` below can be the archive's `reference/` folder, or the original extracted `Parallel10_Research/` folder; it needs `evidence/runs/N0/rows.npy` for the reproduction comparison. Use a fresh `WORK`, not an old cache from different code or inputs.

The recorded environment was Python 3.13.5, NumPy 2.3.5, pandas 2.2.3, SciPy 1.17.0 and scikit-learn 1.8.0, with one numerical thread per process.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONDONTWRITEBYTECODE=1
SOURCE='/absolute/path/Quant Research Take-Home'
WORK='/absolute/path/new-n0-review-work'
PRIOR='/absolute/path/N0_Review/reference'
# Run from the repository root or archive code/ folder.
python -m research.parallel10.run --source "$SOURCE" --work "$WORK" --prepare
python -m research.n0_review.e2e --source "$SOURCE" --work "$WORK"
python -m research.n0_review.run --source "$SOURCE" --work "$WORK" --prior "$PRIOR" --job N0
python -m research.n0_review.run --source "$SOURCE" --work "$WORK" --prior "$PRIOR" --job trace
for job in G_s0 N0_s0 G_f2 N0_f2 G_f3 N0_f3 D1 D5 DC; do
  python -m research.n0_review.run --source "$SOURCE" --work "$WORK" --prior "$PRIOR" --job "$job"
done
python -m research.n0_review.e2e --source "$SOURCE" --work "$WORK" --market
python -m research.n0_review.assess --source "$SOURCE" --work "$WORK"
```

The preparation code has an optional historical absolute-path comparison from its original session; it is skipped when that path does not exist. Independently compare the new `runs/G/rows.npy` first four columns with `PRIOR/evidence/runs/G/rows.npy` to tolerance 1e-10. The supplied archive contains that fresh comparison receipt. `N0` checks its archived economic rows inside the review runner, and `trace` checks all forecasts, positions and economic rows against N0.

The three removal jobs require `concentration.json`, generated by `trace`. D1/D5 use a full-path source ranking and are hindsight influence diagnostics, not a causal new candidate. DC uses the originally specified ex-ante ranking at each refit. No stock is removed from the investment universe. Do not deploy any diagnostic variant based on its observed score.

The inherited runtime requires no on-disk research cache. Shared snapshots accelerate repeated research replays; raw-history N0 and raw-history diagnostic prefixes are also verified. `forecast.npy`, `targets.npy`, raw source arrays and input/cache arrays can use substantial storage; their hashes are in `LARGE_OUTPUT_HASHES.json` and they are omitted from the evidence ZIP. Daily economic rows, all compact summaries and traces, source-stock and executed-stock CSVs, receipts and logs are included.
