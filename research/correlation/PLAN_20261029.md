2026-10-29. Base main ebf1ff1636e263d5fa98ce724cf65dc912d3d0c3. Main stays submission-ready and unchanged. This branch owns one model, CORR. The GLS-alpha model has its own branch. No automatic promotion or submission.

## Hypothesis

F improves factor marginal variance estimates but retains correlations extracted from raw EW126 second moments. Heteroskedastic episodes can distort those correlations. Estimate correlations from factor returns standardized by the variance forecast known before each return, shrink sampling noise, and preserve F's current marginal variances. This targets covariance orientation rather than scalar exposure or a new expected-return predictor. It can fail if correlations drift rapidly, shrinkage suppresses useful structure, or the standardized-return model is misspecified.

Engle/Sheppard (2001), NBER w8554, motivates separating marginal variance and correlation: https://www.nber.org/papers/w8554 . Ledoit/Wolf (2004) motivates shrinkage: https://www.ledoit.net/honey_abstract.htm . The proposed rolling estimator is not a fitted DCC model and not a replication of either paper's empirical results.

## Frozen algorithm — one primary configuration

Compute F's baseline forecasts and causal factor variance multipliers unchanged. Recover each source-day factor return f_s from the same cross-sectional regression as V3. Let v_before_s be the unscaled EW126 factor second moments estimated through s-1. For s>=64 form z_s=f_s/sqrt(max(v_before_s * F_multiplier[s],1e-16)); no future or full-sample normalization.

At target rows t=253+21*k fit sklearn.covariance.LedoitWolf(assume_centered=True) to standardized factor observations from max(64,t-252)..t-1. Normalize its covariance to a correlation matrix; a zero-diagonal factor uses identity for that factor. Hold this alternative correlation until the next scheduled refit. Before the first fit it is identity. No hyperparameter fitting to portfolio score, no seed search, no return/feature selection.

In both virtual and traded allocation books, retain F's marginal factor variances and all specific variances. Let C_base be the original correlation from today's EW126 covariance and C_alt the latest fitted standardized correlation. Use C_new=0.5*C_base+0.5*C_alt; construct covariance with the same factor marginal variances as F. Eigen decomposition with a zero eigenvalue floor yields the factor loading square root. Existing 0.3 factor-risk scale, alpha forecast, cost horizon, limits, beta hedge, market sleeve0.05, and sizing rule are unchanged. All correlation estimates are included in the forecast payload so future-mutation tests inspect them, not only alpha.
