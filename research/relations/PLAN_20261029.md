## Question and limits

Do relationships between stocks with similar published characteristics contain incremental return information, or help estimate stock-specific risk? Distinguish predictive relationships from contemporaneous co-movement; do not call a nearest-neighbor graph an economic network or infer causality from it. Prior residual reversal, richer static characteristic shapes, and generic ML predictors have already been tried. The new hypothesis is peer-relative residual dynamics and characteristic-conditioned variance pooling, not a repeat of an unconstrained nonlinear predictor.

All fifteen years are exposed development data. A causal replay is not a fresh holdout. Limit this wave to TWO primary specifications, retain every failure, and make no result-driven changes to neighbor count, horizons, shrinkage, ridge, feature cap, seeds, or windows. No deep-learning or reinforcement-learning claim.

## Shared graph (frozen)

At published source dates s=0,21,42,... construct Euclidean neighbors from the 13 cross-sectionally standardized, clipped characteristics using the existing basis function's first 13 columns. Each stock uses 32 nearest OTHER stocks, or N-1 if fewer. Include all ties at the boundary (distance tolerance 1e-12), average neighbors equally, and exclude self. For a single stock: peer alpha features zero, risk pooling neutral. Reuse the last graph between scheduled dates; this schedule is based on source row, never total history length. Distances and graph use no returns or future characteristics. Sparse graph multiplication is allowed. All startup cases and graph ties are covered in E2E. No supplied characteristic names are assigned invented economic meanings.

## Primary P: peer-relative residual alpha on unchanged selected GLS

After source day s closes, obtain its market-residual return using beta estimated strictly before s, and regress it on the previous published 26-column characteristic basis with ridge 1e-10 to remove contemporaneous characteristic-factor shocks. Maintain debiased EW means of this idiosyncratic residual at half-lives 5 and 21 days. Four cross-sectional features: own EW5, own EW21, neighbor-average EW5, neighbor-average EW21. Cross-sectionally standardize each with the existing clipping rule, then project off the CURRENT 27-column design (characteristics/squares/beta available after s) using ridge 1e-8. No labels enter this projection.

Train a four-coefficient pooled EW ridge, half-life 1008, ridge 1.0, against the NEXT day's market-residual return minus the selected GLS forecast that was actually available for that label. At forecast t, newest training label is t-1 paired with features built at t-2; current features use t-1. Require 252 matured pairs. Add 0.5 times the learned residual prediction to GLS, with cross-sectional RMS capped to 20% of GLS's current alpha RMS (zero if baseline zero). Keep risk payload, allocation, sizing and 0.05 market sleeve unchanged. No cross-sectional stock IDs, fitted future coefficients, or full-sample normalizers.

Always run explanatory O: own EW5/EW21 only, with identical learning, projection, maturity and cap; O is not a new selectable primary. If P passes its economic shortlist versus G, run one graph negative control using a fixed cyclic relabeling of graph recipients/sources (half-universe cyclic shift, degree preserved) while retaining signals/labels; this is a nondeployable diagnostic and not a permutation-equivariant model claim. P must also beat O by >=0.002 to support peer information, and pass the negative-control comparison if triggered. No alternative sign/horizon if P fails.

## Primary V: peer pooling of specific risk on unchanged selected GLS

Keep GLS alpha and all factor-risk inputs fixed. For each allocation day, let d be F's existing positive stock-specific variance vector. Set peer=graph@d and replace d with d*clip(0.5+0.5*peer/d,0.75,1.5). Apply identically to virtual and traded stock books; keep factor risk, costs, limits and sleeve unchanged. The forecast's alpha/risk payload is unchanged; graphs are reconstructed sequentially from the available characteristics inside rebalance. This changes specific variances, not residual cross-covariances, and is not a GNN.

Always run explanatory VG: replace peer by the same day's global mean(d), with the same blend/bounds. VG is not an eligible primary. V must beat VG by >=0.002 as well as pass the economic shortlist to support a characteristic-relationship contribution rather than generic shrinkage. No penalty/refit settings are tuned.
